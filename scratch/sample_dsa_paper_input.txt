MODULE 1: Linear Data Structures. Arrays, Stacks, and Queues are fundamental linear data structures. A stack is a Last-In First-Out (LIFO) data structure supporting push and pop operations. Queues operate on First-In First-Out (FIFO) principles for task scheduling. 

MODULE 2: Non-Linear Data Structures & Trees. Binary Search Trees maintain left child less than root and right child greater. AVL trees perform LL, RR, LR, and RL rotations to ensure balance factor remains between -1 and +1. 

MODULE 3: Graph Algorithms & Shortest Paths. Dijkstra's algorithm finds single-source shortest paths in weighted graphs with non-negative edge weights. Prim's and Kruskal's algorithms construct Minimum Spanning Trees (MST) for connected weighted graphs. 

MODULE 4: Sorting and Searching. Quick sort uses divide-and-conquer strategy with pivot partitioning. Merge sort achieves O(n log n) worst-case time complexity using recursive merging. 

MODULE 5: Hashing and File Structures. Hash functions convert key values into array indices. Collision resolution techniques include linear probing, quadratic probing, and separate chaining.
