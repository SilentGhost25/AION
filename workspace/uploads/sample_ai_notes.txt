Module 1: Introduction to Machine Learning and Supervised Learning

Machine learning is a subset of artificial intelligence concerned with building systems that learn from data. Supervised learning algorithms learn a mapping function from input features to output targets based on labeled training examples. Common supervised learning tasks include classification, where outputs are discrete class labels, and regression, where outputs are continuous numerical values.

Linear regression models the relationship between dependent continuous scalar response variables and independent explanatory variables using linear predictor functions. Parameter optimization in linear regression typically minimizes the mean squared error (MSE) loss function through analytical closed-form normal equations or iterative gradient descent algorithms. Gradient descent updates parameters in the direction of the negative gradient of the loss function with respect to weight vectors.

Logistic regression is a fundamental probabilistic classification algorithm used for binary and multi-class classification tasks. It applies the sigmoid activation function to map linear combinations of feature vectors into probabilities bounded between zero and one. Cross-entropy loss, also known as log loss, measures the performance of classification models whose output is a probability value between 0 and 1.

Decision trees partition feature space using orthogonal decision boundaries derived by maximizing information gain or minimizing Gini impurity at each split node. Ensemble learning methods combine multiple base models to produce improved predictive performance compared to any single constituent model. Random forests utilize bagging (bootstrap aggregating) and random feature selection to reduce variance without increasing bias. Support Vector Machines (SVM) find optimal hyperplanes that maximize margins between support vectors of different classes in high-dimensional feature spaces using kernel functions like Radial Basis Function (RBF) or Polynomial kernels.

Module 2: Unsupervised Learning and Dimensionality Reduction

Unsupervised learning aims to discover underlying patterns, structures, and groupings within unlabeled datasets. K-means clustering partitions observations into k distinct clusters by minimizing the sum of squared Euclidean distances between data points and cluster centroids. Expectation-Maximization (EM) algorithms iteratively compute maximum likelihood estimates in latent variable models such as Gaussian Mixture Models (GMM).

Principal Component Analysis (PCA) is an orthogonal linear transformation technique that projects data onto lower-dimensional spaces while maximizing variance retention. Singular Value Decomposition (SVD) factorizes matrix representations into singular values and orthogonal vectors, providing the mathematical foundation for latent semantic analysis and matrix factorization techniques in recommendation systems.
